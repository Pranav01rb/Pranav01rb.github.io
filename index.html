Projects

Vehicle-to-Infrastructure (V2I) Based 3D Object Detection and Sensor Fusion

ROS 2 • Autoware • Kalman Filter • CARLA • ScenarioRunner

Summary: This work addresses the occlusion problem in autonomous driving by leveraging Road Side Units (RSU). By integrating infrastructure sensors, the system can see through obstacles like buildings or large vehicles, effectively extending the perception horizon beyond the line of sight of the ego vehicle.

  • - Developed an end to end sensor fusion perception stack by identifying gaps in existing cooperative perception and implementing a real time late fusion framework in Python and ROS2 for 3D object detection, merging onboard LiDAR with infrastructure camera data.
  • - Engineered a dual update Kalman Filter to fuse asynchronous LiDAR and camera data, successfully overcoming network delays and noise to deliver smoother multi sensor state estimation.
  • - Extended the detection range by 252% and reduced RMSE by 43%.
  • - Created and executed four different urban traffic scenarios using CARLA and ScenarioRunner to conduct validation of the proposed pipeline.
  • - Conducted real-world validation using the Ford Mach-E Research Vehicle.

Autoware SceneSeg Semantic Segmentation for Hazard Detection (Autoware Collaboration)

ROS 2 • Autoware • Semantic Segmentation • On-vehicle bring-up

This project focused on the real time deployment of semantic segmentation on a fully autonomous Ford Mach E research vehicle. By optimizing deep learning models for edge hardware, the system provided reliable hazard detection for challenging scenarios like animal related road obstacles, for a CES 2026 event.

  • Optimized and deployed Autoware SceneSeg on vehicle using ONNX and TensorRT to ensure low latency performance.
  • Validated system robustness across public ADAS hazard testing cases including animal related scenarios in collaboration with the Autoware Foundation.
  • Integrated the perception stack with the Autoware ROS2 pipeline to enhance real time scene understanding on the lab research vehicle.

Multi Camera-LiDAR Calibrationfor Multi-View Perception

AprilTag • PnP • SQPnP • Autoware • ROS2

This project involved a major system upgrade from a 135 degree forward facing setup to a comprehensive 360 degree surround perception system. By performing precise intrinsic and extrinsic calibration across multiple sensors, I enabled accurate spatial alignment which is the foundation for reliable multi sensor fusion and obstacle detection.

  • Led a system upgrade to a 360 degree surround perception suite utilizing a 6 camera and 2 LiDAR sensor configuration.
  • Executed intrinsic and extrinsic calibration using AprilTag based PnP and SQPnP optimization to achieve precise spatial alignment.
  • Integrated the calibrated sensor outputs into the Autoware ROS 2 pipeline to improve detection stability and spatial accuracy.

Traffic Light & Sign Detection in Adverse Conditions

YOLOv11n • LISA + CARLA augmentation

This research addresses the drop in perception accuracy caused by adverse weather and motion blur. By leveraging a combination of synthetic data generation and a custom weighted loss function, I developed a more resilient detection system that maintains high performance even when traditional models fail due to environmental perturbations.

  • Engineered a YOLOv11n based detection pipeline trained on the LISA dataset and supplemented with synthetic data from the CARLA simulator to represent rare and difficult scenarios[cite: 46, 62, 166].
  • Implemented a custom loss function with enhanced localization penalties for small bounding boxes and class weighting to address visibility challenges and dataset imbalance[cite: 120, 122, 123].
  • Applied extensive data augmentation techniques including randomized motion blur kernels, Gaussian blur for fog simulation, and raindrop effects to improve model robustness[cite: 127, 128, 130, 133].
  • Achieved a baseline mAP50 of 88.6 percent and maintained 78.1 percent mAP50 across augmented tests featuring motion blur, fog, rain, and occlusions[cite: 31, 170, 172].
